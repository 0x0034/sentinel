# 使用 Chromium 渲染阿里云 CVE 列表

阿里云 CVE 列表的普通 HTTP 请求返回 WAF 挑战，参考项目使用浏览器读取 HTML；经用户授权，本机普通无头 Chrome 已成功读取两页真实列表。因此新增来源由 Go 调用 Chromium 渲染后解析列表，接受浏览器依赖带来的镜像体积、临时存储和进程生命周期管理成本，以取得已验证可读的业务内容；现有 RSS 继续使用普通 HTTP 抓取。

首版只读取列表字段和真实详情链接，详情抓取未验证成功，不纳入本轮。浏览器退出码或 HTTP 200 均不构成采集成功，必须通过业务结构和分页校验；Linux/amd64 容器中的实际可用性仍须独立验收，不依赖本机成功推断生产可用。

2026-10-22 后续变更：详情已验证可读，用户要求补充详情字段；“只读取列表”的边界由 [ADR-0005](0005-vulnerability-details.md) 更新。
