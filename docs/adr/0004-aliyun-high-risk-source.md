# 默认监测阿里云高风险列表

用户将监听目标明确为 `https://avd.aliyun.com/high-risk/list`。该列表采用 AVD 编号并提供漏洞状态，没有 CVSS 列，也包含无 CVE 编号的条目；无法仅替换原 CVE 列表 URL 后沿用相同表头。

新增 `aliyun_high_risk` 来源类型及独立订阅 ID，示例默认使用它；保留 `aliyun_cve` 兼容已有配置。两者共享浏览器、分页、投递与首次发现时间口径，但分别校验对应表头，避免将来源切换误认作空列表或普通内容更新。已有 ID 改变来源类型会报错，新 ID 首次完整采集静默建立基线。

原样保存列表漏洞状态，仅提取标题明确出现的 CVE 编号；不从 AVD 推导 CVE，也不根据“高风险”或 PoC、EXP 等标记推算 CVSS。状态存入既有漏洞 JSON 字段，数据库维持 schema 2。只读列表字段与实际详情链接，仍不批量抓取详情。

实测高风险第 3、4 页边界重复同一 AVD 且字段一致；允许高风险来源的相同跨页记录去重，整页重复、同 AVD 字段冲突和页码错误仍拒绝整个窗口。CVE 列表继续严格拒绝跨页重叠。
