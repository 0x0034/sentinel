## 容器与交付

指定 Go/Alpine 基础镜像、Go 1.27.2 编译器、阿里云 APK 源及 linux/amd64 架构沿用既有约束，运行阶段增加 Chromium。

Chromium 实际版本为 Alpine 提供的 `142.0.7444.59`。运行用户为 `65532:65532`，根文件系统只读，`/tmp` 为 512 MiB 的 noexec tmpfs，全部 capabilities 移除，启用 `no-new-privileges` 和容器 init。当前平台拒绝 Chromium 创建 namespace sandbox，因此容器示例显式启用 `browser.no_sandbox`；独立 Chromium sandbox 未启用，隔离依赖容器。支持 Chromium sandbox 的宿主环境可设为 `false`。

本次 APK 构建通过临时主机转发器加速，转发器仅从 `https://mirrors.aliyun.com/alpine/v3.22/` 下载，保持系统 TLS 校验和 Alpine 包签名校验。最终 `/etc/apk/repositories` 仍为阿里云 v3.22 main/community，镜像运行不依赖该转发器。

最终镜像通过两次独立容器启动的样例持久化测试：AVD 身份、首次发现时间、初始化基线标记与漏洞字段保持一致，发送任务始终为 0。17:18 的最终镜像真实采集验收也保存了前 5 页共 150 条基线，发送任务为 0，数据库版本为 2。

## 边界

本轮仅接入 `/nvd/list` 的 CVE 库，默认前 5 页，约 150 条；不提供全库归档、任意停机时长后的完整补采或窗口外旧条目的持续更新。提高页数时，新进入窗口的历史记录会成为首次发现。

披露日期是来源日期，昨日新发现按 Sentinel 首次成功采集时间统计并排除初始化基线。详情页未验证成功，本轮只使用列表字段和原文链接。生产网络或站点策略变化仍可能阻止 Chromium 访问，失败页面不会推进基线或成功状态。

已有公共 RSS 地址曾返回 HTTP 403，此限制独立于新增 CVE 来源；本次没有将两种来源的验证混为一谈。
