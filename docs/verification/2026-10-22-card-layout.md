# Sentinel 0.2.0-rc.4 飞书卡片排版验收

日期：2026-10-22～23。

## 输出变化与文档依据

根据[飞书自定义机器人指南](https://open.feishu.cn/document/client-docs/bot-v3/add-custom-bot)及[卡片 JSON 2.0 结构](https://open.feishu.cn/document/uAjLw4CM/ukzMukzMukzM/feishu-cards/card-json-v2-structure)，新通知使用 JSON 2.0，保留红色标题。普通文本组件区分正文标题、正文及辅助说明；阿里云评分和 CVSS、漏洞标识和日期信息使用两列排布，窄屏使用 `stretch` 上下堆叠。漏洞描述、解决建议和受影响软件情况分别用固定加粗标题与独立文本组件呈现。

原文按钮改为 JSON 2.0 的独立 `button` 与 `open_url` 行为，增加聊天列表摘要。来源内容保持纯文本，避免版本范围、代码、Markdown 和 @ 标签被解释为卡片指令。采集失败说明显示红字。适用组件文档已列入 [RSS 设计](../design/rss-feishu.md#已核实的接口和环境事实)。

## 已执行检查

- Go 1.27.2 执行 `make check test build` 通过，包括格式、vet、全部竞态测试及构建。
- 新增结构回归覆盖独立标题和章节、窄屏布局、原文按钮、评分来源、来源文本原样显示以及不安全链接排除。
- 120 条短 RSS / 漏洞记录的汇总回归确认：每条恰好出现一次，每张不超过 200 个元素（含嵌套文本）及 18 KiB。现有长文本、零分、未知字段、时区、空汇总和失败重试测试通过。
- `linux/amd64` 镜像构建并启动成功，输出 `sentinel 0.2.0-rc.4 go1.27.2 linux/amd64`，运行用户为 `65532:65532`；容器的 APK 仓库仍为 `https://mirrors.aliyun.com/alpine/v3.22/{main,community}`。构建使用上一轮从同一阿里云源下载的本地公开 APK 缓存，并保持 Alpine 包签名校验；临时缓存服务已关闭。
- Compose 使用占位环境变量通过配置检查，仓库凭证模式扫描与 `git diff --check` 通过。

## 升级边界

需要飞书客户端 **7.20 及以上**；更旧版本只能看到标题和升级提示。新布局只应用于升级后生成的通知，SQLite 中既有待发 payload 保持原样。四项详情的采集、缓存、截断提示及基线/去重语义沿用 rc.3。

没有部署生产常驻服务。此版本不改变来源可达性；此前公共 RSSHub 返回 HTTP 403 的限制继续适用。
