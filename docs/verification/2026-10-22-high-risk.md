# Sentinel 0.2.0-rc.2 高风险列表验收

日期：2026-10-22，时区 Asia/Shanghai。监听目标：`https://avd.aliyun.com/high-risk/list`。

## 行为与来源事实

默认配置切换为 `aliyun_high_risk`，使用独立订阅 ID `aliyun-high-risk`；原 `aliyun_cve` 配置继续兼容。两类来源均以 AVD 去重，首次完整采集建立静默基线，昨日汇总按首次发现时间并排除基线。

真实列表表头为 AVD 编号、漏洞名称、漏洞类型、披露时间、漏洞状态。卡片保存并展示状态，只从标题提取明确出现的 CVE 编号；来源未提供 CVSS，不推算评分。实测前五页 150 行包含 149 个独立条目，18 条标题没有 CVE 编号。

`AVD-2025-32462` 在第 3 页末尾与第 4 页开头重复出现，字段完全一致。首次真实验收触发原有严格重叠保护，未建立基线；修复后高风险来源允许完全一致的跨页记录去重，仍拒绝字段冲突、整页重复、错误页码、挑战页及结构异常。原 CVE 来源仍严格拒绝跨页重叠。
